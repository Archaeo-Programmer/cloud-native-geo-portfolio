# Cloud-Native Geospatial Portfolio

Hands-on projects and open-source contributions in cloud-native geospatial data:
GeoParquet, DuckDB, STAC, COG, Zarr, Icechunk and browser mapping.

This started after the [Cloud-Native Geospatial Forum 2026](https://2026.cloudnativegeo.org)
(Snowbird, Utah, October 2026). Each project is written up as a short case study:
the problem, the data, the approach, a measured result and what was delivered.

## Projects

| Phase | Project | Stack | Status |
| --- | --- | --- | --- |
| 1 | [Buildings in FEMA flood zones](phase1-flood-buildings/) | GeoParquet, DuckDB spatial, Overture Maps | Done |
| 2 | Static STAC catalog | STAC, rustac, Source Cooperative | Planned |
| 3 | NASA imagery as web tiles | COG, earthaccess, TiTiler | Planned |
| 4 | Virtual data cube | Zarr, VirtualiZarr, Icechunk, xarray | Planned |
| 5 | Browser map of all outputs | deck.gl-raster, Lonboard, DuckDB-WASM | Planned |
| 6 | AI-ready EO dataset | Major TOM, TACO, embeddings | Planned |
